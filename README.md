# دور – Turn

بازی مهمانیِ حدس کلمه برای ۴، ۶ یا ۸ نفر با یک گوشی. بازیکن‌ها دور میز می‌نشینند، هم‌تیمی‌ها روبه‌روی هم. هر نفر کلمهٔ روی صفحه را برای هم‌تیمی‌اش توضیح می‌دهد؛ با حدس درست، گوشی به نفر بعد می‌رسد. وقتِ هر دور که تمام شود، تیمی که گوشی دستش مانده ۳۰ ثانیه جریمه می‌شود. تیمی که در پایان بیشترین زمان را دارد برنده است.

A pass-the-phone word-guessing party game (React + TypeScript + Vite). Runs fully in the browser; no server is needed to play.

## اجرا روی کامپیوتر خودت

نیاز: Node.js 22 یا بالاتر.

```bash
npm ci          # نصب وابستگی‌ها (دقیقاً طبق package-lock.json)
npm run dev     # اجرای محلی روی http://localhost:3000
npm test        # همهٔ تست‌ها (vitest)
npm run lint    # بررسی تایپ‌ها (tsc --noEmit)
npm run build   # ساخت نسخهٔ نهایی در پوشهٔ dist
```

## انتشار (GitHub Pages)

با هر push روی `main`، ورک‌فلوی `.github/workflows/deploy.yml` سایت را می‌سازد و منتشر می‌کند.
برای اینکه کار کند، یک بار باید در گیت‌هاب روشن شود:

1. **Settings → Pages**
2. در **Build and deployment → Source** گزینهٔ **GitHub Actions** را انتخاب کن.
3. تب **Actions → Deploy to GitHub Pages → Run workflow**.

نشانی سایت: `https://maryamjaberi.github.io/Dour-new/`

> تا وقتی قدم ۲ انجام نشده، ورک‌فلو در مرحلهٔ «Setup Pages» خطا می‌دهد. این تنظیمِ مخزن است، نه مشکل کد.

## ساختار

| مسیر | چه چیزی |
|---|---|
| `App.tsx` | وضعیت کل بازی: صفحه‌ها، تایمر، استخر کلمه‌ها، تاریخچه |
| `screens/` | صفحه‌ها: شروع، تنظیمات، دسته‌ها، نام بازیکنان، چیدمان، بازی، پایان، تاریخچه، راهنما |
| `components/` | تایمر، دایرهٔ بازیکنان، مودال‌ها، شخصیت تیم‌ها، راهنمای نصب |
| `words.ts` | بانک کلمه (۲۴۲ کلمه، ۸ دسته، ۳ سطح، ۹ زبان) |
| `translations.ts` | متن‌های رابط کاربری در ۹ زبان |
| `soundManager.ts` | همهٔ صداها (ساخته‌شده با Web Audio؛ فایل صوتی ندارد) |
| `utils/shuffle.ts` | بُر زدن بی‌طرف (Fisher–Yates) و جلوگیری از تکرار پشت‌سرهم |
| `firebase.ts` | ورود اختیاری و ذخیرهٔ ابری تنظیمات و تاریخچه |
| `public/` | `manifest.json` و آیکون‌های نصب |
| `tests/` | ۱۶۳ تست: منطق بازی، ۱۰۰ سناریوی شبیه‌سازی، صدا، مسیرهای کاربر |
| `STATE_MACHINES.md` | نقشهٔ وضعیت‌های بازی برای توسعه‌دهنده |

## مشکلات شناخته‌شده

| مشکل | شدت | توضیح |
|---|---|---|
| آفلاین کار نمی‌کند | متوسط | service worker ندارد و Tailwind و فونت از CDN می‌آیند. راه‌حل: نصب Tailwind در بیلد + `vite-plugin-pwa`. |
| سه دستهٔ خالی | متوسط | «احساسات»، «صفت‌ها» و «تکنولوژی» در `constants.tsx` هستند ولی در `words.ts` کلمه‌ای ندارند. |
| صفحه خاموش می‌شود | جزئی | در دورهای طولانی گوشی قفل می‌شود. راه‌حل: Screen Wake Lock API. |
| تایمر در پس‌زمینه | جزئی | اگر مرورگر به پس‌زمینه برود، تایمر تقریباً می‌ایستد ولی بازی «متوقف» نشان داده نمی‌شود. |
| آیکون‌ها موقت‌اند | جزئی | `public/icon-*.png` جایگزین موقت است تا لوگوی نهایی برسد. |
| حجم بسته | جزئی | یک فایل JS حدود ۱٫۱ مگابایت (بیشترش Firebase). |
